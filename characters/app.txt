# The app's own identity: Lucy Desktop. Every -Character build uses these, whichever character it wears, so the app
# never clashes with a real Capri on the same PC and switching characters never moves settings or autostart.
# Same format as a character's names.txt: "Capri's code" => "ours", exact words, applied to a copy of the code.
# What stays Capri's on purpose: Capri.exe (the program's file name), downloads of Capri's voice pack and HD voice from
# her releases, links to Lachy's website and help, and "Capri-Desktop" as the name it gives websites.
